# ArenaGo

Sports arena booking platform MVP — frontend only, hardcoded data.

**Tagline:** Book your court. Show up and play.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Demo accounts

| Role | Email | Password |
|------|-------|----------|
| Player | player@arenago.com | play123 |
| Arena Owner | owner@arenago.com | own123 |

## Build & deploy

```bash
npm run build
```

Deploy the `dist` folder to Vercel (Vite preset, no env vars required).

## Stack

React 19, TypeScript, Vite, Tailwind CSS 3.4, React Router, Framer Motion, Lenis, GSAP, Embla Carousel, Recharts
